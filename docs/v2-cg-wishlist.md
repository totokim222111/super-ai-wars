# 카본 삽화 완료 목록

물결 5: 신규 28장 완료·대본 연결. 모든 그림은 글자·실제 로고 없이 제작했고, 사용자 얼굴을 그리지 않는다. 원문 장면 설명은 아래 기록으로 보존한다.
