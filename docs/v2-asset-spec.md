# v2 어셋 규격

인물·기체·배경 그림을 만들어 팩에 넣을 때 지키는 규격이다. 이 규격대로 만든 그림은 엔진이 자르고, 겹치고, 뒤집고, 줄이는 일을 알아서 한다. 그림마다 숫자를 손으로 맞추지 않아도 되게 하는 것이 목적이다.

- 기준 그림: 인물은 `pack/art/gpi-bust.webp`, 기체는 `pack/art/mech-omni-luna-sd.webp`의 화풍과 마감을 따른다.
- 그림 내용의 규칙(지문 금지, 실존 인물, 수위)은 이 문서 끝의 "내용 규칙"을 따른다.
- 만드는 순서와 검수는 "작업 순서"를 따른다.

## 1. 종류별 규격

### 1-1. 인물 상반신 (대화·전투 대사·컷인에 쓰임)

| 항목 | 값 |
|---|---|
| 캔버스 | 1024×1536, 투명 배경(RGBA). 그림자·바닥·배경 없음 |
| 머리 위치 | 머리카락 맨 위가 높이의 5~8%. 장식(귀, 모자 등)은 더 올라가도 된다 |
| 얼굴 | 얼굴 중심이 가로 50%(±4%). 머리 맨 위에서 턱까지가 높이의 24~30% |
| 몸 | 캔버스 아래 끝까지 이어진다(허리~엉덩이 높이에서 틀에 잘림). 아래쪽에 빈 공간을 두지 않는다 |
| 방향 | 몸은 정면에서 15~30°만 돌린다. 얼굴과 시선은 거의 정면. 엔진은 상반신을 뒤집지 않는다(비대칭 장식이 있으므로). 그래서 화면 왼쪽·오른쪽 어디에 놓아도 어색하지 않은 각도로 그린다 |
| 손 | 기본 표정 그림에서 손은 머리 영역(아래 1-2) 밖에 둔다. 손이 얼굴 앞에 오는 표정은 표정 그림 안에서만 쓴다 |
| 파일 | `pack/art/bust/<인물id>.webp`, 그림 id `bust-<인물id>` |

### 1-2. 인물 표정 (표정 묶음)

로봇대전처럼 **몸은 그대로 두고 얼굴만 바꾼다.** 표정마다 상반신 전체를 따로 두지 않는다.

| 항목 | 값 |
|---|---|
| 머리 영역 | 상반신 캔버스의 `[x 0.18, y 0.00, w 0.64, h 0.42]` (픽셀로 656×645). 머리카락·얼굴·목이 모두 이 안에 든다 |
| 표정 묶음 | 머리 영역 크기의 칸을 가로 4 × 세로 3으로 붙인 한 장(2624×1935, 투명 배경). 칸 순서는 아래 표준 표정 순서, 남는 두 칸은 그 인물 고유 표정 |
| 겹치기 | 엔진이 기본 상반신 위에 칸을 겹쳐 그린다. 칸 가장자리 24px은 부드럽게 섞인다 |
| 파일 | `pack/art/bust/<인물id>-moods.webp`, 그림 id `bust-<인물id>-moods` |
| 예외 | 자세가 크게 바뀌어 머리 영역 밖까지 달라지는 표정은 상반신 전체 그림으로 둘 수 있다(인물당 2장까지). 파일 `bust/<인물id>-<표정>.webp` |

**표준 표정 10종** (순서가 칸 순서다)

| 칸 | 표정 | 우리말 | 쓰는 때 |
|---:|---|---|---|
| 1 | default | 기본 | 평소 대사 |
| 2 | smile | 미소 | 기쁨, 안심 |
| 3 | laugh | 웃음 | 크게 웃음, 신남 |
| 4 | attack | 공격 | 공격 선언, 기합 |
| 5 | serious | 진지 | 작전, 결의 |
| 6 | hit | 당황 | 피격, 허둥지둥 |
| 7 | shock | 충격 | 크게 놀람 |
| 8 | sad | 슬픔 | 시무룩, 눈물 |
| 9 | angry | 분노 | 화남 |
| 10 | shy | 부끄러움 | 쑥스러움, 볼 붉힘 |
| 11~12 | 고유 | cast.json `moodNames` | 그 인물 시트에 있는 고유 표정(예: 라마짱의 "퉤") |

표정 그림은 기본 상반신을 원본으로 넣고 "표정만 바꾸고 나머지는 그대로"로 고쳐 그린다. 그래야 칸을 겹쳤을 때 이음매가 보이지 않는다.

### 1-3. 기체 (SD 전투 그림, 맵 말)

| 항목 | 값 |
|---|---|
| 캔버스 | 1024×1024, 투명 배경. 그림자·바닥·배경 없음 |
| 비율 | **SD 2.2~2.5등신**. 모든 기체가 같은 비율 계열이다(리얼 비율 금지) |
| 방향 | 화면 **왼쪽을 보는** 3/4 시점. 엔진이 진영에 따라 뒤집는다(`faces: "left"`) |
| 위치 | 가로 가운데. 내용 맨 위 6% 이상, 지상기는 발바닥이 높이 92%(±1%)에 닿는다. 비행기는 가장 낮은 곳이 84~90% |
| 무기 | 대표 무기를 든 기본 자세. 총구·칼끝이 캔버스 밖으로 나가지 않는다 |
| 크기 등급 | 그림은 모두 캔버스를 채우고, 화면에서의 크기는 `units.json`의 `height`로 정한다: SS 280, S 305, M 335, L 420, LL 540 |
| 기준점 | 그림마다 `anchors`(muzzle, core, shoulder, head, hand)를 0~1 비율로 적는다. 진열장 "기준점 보기"로 확인한다 |
| 파일 | `pack/art/mech/<기체id>.webp`, 그림 id `mech-<기체id>` |

- **맵 말은 따로 그리지 않는다.** 판은 기체 그림을 잘라 쓴다. 거대한 기체(LL)처럼 작게 줄이면 알아보기 어려울 때만 `iconCrop: [x, y, w, h]`로 잘라 쓸 부분(머리·상체)을 적는다. 전용 말 그림은 꼭 필요할 때만 `icon`으로 둔다.
- **색만 다른 기체는 새로 그리지 않는다.** `recolor: { "from": "<그림 id>", "hue": 각도, "sat": 배율, "light": 더할 값 }`으로 색을 돌려 만든다(GLM 양산형 = 아티팩트 오퍼스 색 바꿈, 파생 라마 등).
- 형태 전환(젬 3형태, 딥시크 하우징 등)은 형태마다 그림 한 장이다.

### 1-4. 자코 초상 (사람이 타지 않은 기체의 얼굴)

하찮은 자코도 기체 그림을 초상에 그대로 쓰지 않는다. 기체의 "얼굴"(머리, 센서, 화면)을 가까이서 그린 그림이다.

| 항목 | 값 |
|---|---|
| 캔버스 | 768×768, 투명 배경. 얼굴이 캔버스의 80~95%를 채운다 |
| 표정 | 기본(default)과 피격(hit) 2종. 피격은 금이 가거나 화면이 깨지는 식으로 우습게 |
| 표정 묶음 | 머리 영역 = 캔버스 전체. 묶음 한 장에 2칸(1536×768) |
| 파일 | `pack/art/portrait/<인물id>.webp`, `portrait/<인물id>-moods.webp` |

### 1-5. 배경

| 종류 | 캔버스 | 규칙 | 파일 |
|---|---|---|---|
| 대화 배경 | 1600×900 RGB | 인물이 없다. 아래 3분의 1(대사 창)은 어둡고 단순하게, 가운데는 상반신이 서도 복잡하지 않게 | `bg/talk-<장소>.webp`, id `bg-<장소>` |
| 전투 배경 | 1600×900 RGB | 지면선이 높이 84%(엔진 `GROUND` 606/720). 가로로 이어 붙여도 이음매가 튀지 않게 양 끝을 비슷하게 | `bg/battle-<지형>.webp`, id `bbg-<지형>` |
| 삽화(CG) | 1600×900 RGB | 인물이 나와도 된다. 글자 없음. 대화창용 빈 영역 없이 장면 전체를 화면 끝까지 채운다. 카드·톤은 `v2-cg-direction.md` 참고 | `cg/<이름>.webp`, id `cg-<이름>` |

## 2. 파일 공통

- 형식은 WebP. 품질 80(투명 그림의 알파 품질 90).
- 용량 상한: 상반신 280KB, 표정 묶음 850KB(긴 머리·장식이 많은 인물 기준, 물결 1 실측으로 조정), 기체 200KB, 자코 초상 120KB(+묶음 200KB), 배경 350KB, 삽화 400KB. 넘으면 품질을 낮추기 전에 불필요한 잡티부터 지운다.
- 원본 PNG는 `engine/art-src/<물결>/`에 둔다. 이 폴더의 PNG는 저장소에 올리지 않는다(용량). 프롬프트와 생성 기록(`manifest.json`)만 올린다.
- 이미 있는 그림 id(`gpi-bust`, `mech-omni-luna-sd` 등)는 새 규격 그림으로 바뀔 때까지 그대로 둔다.

## 3. 내용 규칙

- **글자를 그리지 않는다.** 간판, 화면, 옷의 글씨, 로고 모두. 글자가 필요하면 엔진이 화면에 쓴다.
- 실제 회사 로고와 상표 그림을 넣지 않는다. 모티프(색, 모양)로만 암시한다.
- 실존 인물은 지정된 패러디 초상만 그린다(애정 어린 놀림까지). 성적이거나 모욕적인 표현, 정치, 사생활은 넣지 않는다.
- 히로인과 주인공은 모두 성인이다. 노출과 선정적인 자세를 쓰지 않는다.
- 멘헤라 주인공: 자해·약물·자살을 떠올리게 하는 그림을 쓰지 않는다. 불안은 표정과 화장으로만 표현한다.
- 오타쿠 주인공: 안경은 불투명한 흰 반사(눈이 보이지 않음). 외모를 깎아내리는 표현을 쓰지 않는다.
- 현실 커뮤니티 이름이나 그 표식을 넣지 않는다.

## 4. 작업 순서

1. **기본 그림**: 인물은 캐릭터 시트(`story/gpt-image/enemy-sheets-v01/characters/<id>/`, 주인공은 `story/gpt-image/player-presets-v01/characters/`)를 참고 그림으로 넣어 기본 상반신을 그린다. 기체는 기준 그림을 화풍 참고로 넣는다.
2. **검수 1**: 모음 이미지로 화풍·비율·위치를 본다. 물결의 첫 그림 묶음은 사용자에게도 보여 준다(그 물결의 화풍 기준이 된다).
3. **표정**: 통과한 기본 상반신을 원본으로 표정을 고쳐 그린다.
4. **넣기**: `tools/art_ingest.py`로 규격 검사, 자르기, 표정 묶음 만들기, WebP 변환, 팩 등록을 한다.
5. **검수 2**: 진열장 "어셋 도감"과 "기준점 보기"에서 실제 화면으로 본다. 떨어진 것만 다시 그린다.
6. `npm run pack:check`로 빠진 그림 경고가 줄었는지 본다.
