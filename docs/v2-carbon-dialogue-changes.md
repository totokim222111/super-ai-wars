# 카본 1~15화·엔딩 대사 변경 대조

각 화 원문과 승인 패치를 비교했다. 1·2화는 턴 60, 6화는 턴 24·33, 8화는 턴 33과 외형 낭독 3줄 편집, 10화는 턴 42 선언과 턴 60 옥상 7명 판을 반영했다. 11화는 턴 45, 12화는 턴 48 호명 패치, 15화 뒤 엔딩은 턴 57을 반영했다. 12화 이름 허락·JEPA 조우에도 사용자 지시의 호감 30 기준을 적용하고 낮을 때 애칭으로 바꾼 줄을 기록했다. 3~5·7·9·13·14화는 대사를 바꾸지 않았다.
